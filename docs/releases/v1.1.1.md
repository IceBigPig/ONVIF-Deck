## 系统要求

- Apple Silicon：M1、M2、M3、M4 或后续 Apple 芯片；
- macOS 11 Big Sur 或更高版本；
- 摄像头与 Mac 网络互通，并且已经启用 ONVIF。

此版本不支持 Intel Mac。Intel 用户仍可按照项目 README 从源码运行。

## 安装

### 使用 DMG

1. 下载并打开 DMG；
2. 将“ONVIF设备工作台”拖入“应用程序”；
3. 在“应用程序”中启动。

### 首次打开提示

当前应用使用临时签名，尚未使用 Apple Developer ID 签名和公证。如果
macOS 阻止首次启动，请按住 Control 点击应用，选择“打开”，再确认“打开”。
请只下载本仓库 Release 页面提供的文件，并使用下方 SHA-256 值校验文件。

## 本次功能

- 扫描局域网中的 ONVIF 摄像头；
- 读取 ONVIF Media1 / Media2 设备和 Profile 信息；
- 按视频源识别多通道、主码流、子码流和辅助码流；
- 支持单画面、四分屏、九分屏 RTSP 预览和独立码流切换；
- 使用系统钥匙串记忆摄像头凭据；
- 复制设备信息、码流信息以及带 URL 编码凭据的 RTSP 地址；
- 内置 FFmpeg，无需另外安装播放器或 Python 环境。

## 已知限制

- 未经过 Apple 公证，首次运行需要通过右键菜单选择“打开”；
- WS-Discovery 依赖 UDP 组播，访客 Wi-Fi、AP 隔离、VLAN 或防火墙可能阻止扫描；
- 多路预览能力取决于摄像头连接限制、网络带宽和 Mac 解码性能；
- 不同厂商的 ONVIF 实现可能返回不完整或厂商自定义的 Profile 信息。
